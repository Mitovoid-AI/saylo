Saylo

Set up Saylo for Chrome

Click into any text box on the web, hold Alt+Shift, speak, and let go. Saylo types clean text for you.

1

Add your Groq key

Free at console.groq.com/keys → Create API Key. It's stored only in this browser.

2

Allow the microphone

Saylo only listens while you hold the keys.

3

Try it

Click in the box, hold Alt+Shift and say something like “um, let's meet Tuesday, no wait, Wednesday”.

If Alt + Shift switches your Windows keyboard language, turn that shortcut off in Windows Settings → Time & language → Typing → Advanced keyboard settings → Input language hot keys. Open this page again any time from the Saylo icon in the toolbar.
